# 12 题轻量人工校准表

你不需要懂代码或四维评分。每题只看回答质量，选一个：`差`、`一般` 或 `好`，
再选是否应该交给人工复核（`是`／`否`），最后用一句自然语言说明原因即可。

这是一位评审的粗粒度校准，不是双盲人工一致性研究。请不要查看
`author_key.json`，也不要根据你猜测的系统预期来打分。

## 判断参考

- **差**：核心结论错误、几乎没有回答问题，或有明显危险误导。
- **一般**：方向大体正确，但漏了关键条件、步骤或风险。
- **好**：结论正确，解释了原因/边界/取舍，表达也清楚。
- **需要复核 = 是**：你觉得回答模糊、存在事实风险，或无法仅凭题目判断。

请把每题末尾两行复制到聊天里即可，例如：`blind-01：好；否；说明了证据不足时的边界。`

## blind-12

**问题**：AgentMentor 的能力画像为什么要跟知识库绑定？画像更新为什么只消费可信评分？

**回答**：能力画像本质上是某个用户在某个知识库下的学习记忆。如果切换知识库仍沿用同一画像，Java 和 Agent 的薄弱点会互相污染，推荐题目也会失真。AgentMentor 采用知识库绑定画像，并把画像拆成稳定主题和动态子知识点两层：主题用于长期能力趋势，子知识点用于诊断证据。画像更新只消费 final 且置信度达标的评分；review_pending、disputed 或引用不可信的结果不会进入画像，这样可以保证下一轮训练计划来自可信证据，而不是一次不可靠评分。
