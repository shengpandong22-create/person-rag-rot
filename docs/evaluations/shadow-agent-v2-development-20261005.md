## 失败机制

对于已有可行动 evidence 的固定目标场景，模型仍多次选择已经执行过的首工具。V2 executor 正确将重复工具调用拒绝并 fallback，因此没有业务风险，但它不满足“模型能稳定遵守补充工具约束”的演示资格。

这也解释了为什么其他业务结果仍是100%：fallback 使用确定性策略导出动作。该安全结果不能被误称为模型决策成功。

## 决策

关闭 Shadow Agent V2 的真实模型实验线：

- 不在本数据集上继续修改 prompt 或重复运行；
- 不新增工具或写权限；
- 不开启 feature flag、不接前端、不作为90分项目的演示能力；
- 保留 V1/V2 的失败报告和零污染审计，作为“模型能力与业务策略分离”的工程证据。

现有只读 Agent executor 可以保留为默认关闭的技术原型，但不再继续围绕它投入优化。项目回到已验证的 RAG、状态机、评分和评测闭环作为核心亮点。
