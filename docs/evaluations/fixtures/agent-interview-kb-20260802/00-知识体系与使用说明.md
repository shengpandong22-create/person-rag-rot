# AI Agent 开发面试知识体系

本资料集用于 AgentMentor 的检索问答、面试出题和能力画像验收。每个主题独立成文，题目强调定义、机制、工程取舍、失败模式和验证方法，不以背诵框架 API 为目标。

## 稳定主题

1. RAG：数据摄入、切分、检索、引用、评估和边界控制。
2. LangChain：Agent 运行时、中间件、结构化输出与组件抽象。
3. LangGraph：状态图、Checkpoint、中断恢复、人工介入和流式事件。
4. 上下文与记忆：短期状态、长期记忆、上下文工程、压缩与隔离。
5. 工具调用与 MCP：工具契约、执行闭环、权限、安全与协议接入。
6. 评估与可靠性：数据集、指标、Rubric、模型裁判、回归和降级。
7. Agent 工程化：可观测性、安全、成本、部署和故障恢复。

## 回答结构

推荐使用“结论 → 核心流程 → 风险边界 → 工程方案 → 验证指标”的结构。回答引用资料时必须区分文档事实与个人推断；证据不足时应明确降级，而不是补全不存在的事实。

## 评分建议

- 正确性：概念与机制是否准确。
- 完整性：是否覆盖主流程和关键边界。
- 推理性：能否解释取舍、失败模式与因果关系。
- 表达性：结构是否清楚，是否能让面试官追问和验证。
