# 工具调用与 MCP 面试资料

## 核心知识

工具调用由模型提出结构化调用意图，宿主应用校验参数、权限和预算后执行，再把结果作为观察返回模型。模型不能直接获得系统权限，安全边界由宿主负责。

可靠工具需要输入 Schema、输出契约、超时、重试边界、幂等性和审计。读取类工具通常可安全重试；写操作必须使用幂等键或业务唯一约束，必要时采用审批和补偿。工具错误应分类为参数错误、权限拒绝、可重试依赖故障和不可恢复业务错误。

MCP 为模型应用连接外部工具、资源和提示提供统一协议。协议统一不等于权限统一；客户端仍需决定连接哪些 Server、暴露哪些能力、如何传递身份，以及如何防范恶意内容和越权调用。

## 常见面试题

### 1. 工具调用的完整闭环是什么？

参考答案要点：模型选择工具并生成参数，应用校验、授权、执行和记录，结果返回模型，模型再决定继续调用或完成。说明最大步数、超时和终止条件。

### 2. 如何保证写工具不重复执行？

参考答案要点：客户端或工作流生成稳定幂等键，服务端用唯一约束保存执行结果；重试返回第一次结果。事务外副作用还需 Outbox、状态机或补偿。

### 3. MCP 解决了什么问题？

参考答案要点：标准化能力发现和调用接口，降低每个数据源单独适配成本；不解决工具可信、业务授权、数据质量和 Prompt Injection。

### 4. 如何防范工具滥用？

参考答案要点：最小权限、允许列表、参数约束、沙箱、敏感写操作审批、速率与成本限制、审计日志，以及把工具结果视为不可信输入。
