# Java 后端面试知识体系

本知识库用于验证 AgentMentor 的跨知识库画像隔离，同时作为 Java 后端复习资料。稳定主题为 Java 后端，诊断子知识点包括 JVM、并发、Spring 与事务、生产可观测性。

回答建议采用“概念 → 底层机制 → 工程场景 → 风险与验证”的结构，不只背诵结论。
