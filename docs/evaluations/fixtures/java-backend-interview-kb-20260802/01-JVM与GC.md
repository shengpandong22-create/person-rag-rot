# JVM 与 GC

## 运行时区域

JVM 规范定义堆、方法区、Java 虚拟机栈、PC 寄存器和本地方法栈等运行时区域。堆在线程间共享，用于分配对象与数组；每个线程拥有自己的 PC 和虚拟机栈。规范不强制具体内存布局和垃圾回收算法，不能把某个 HotSpot 实现细节当作 JVM 规范本身。

类加载经历加载、链接和初始化。链接包含验证、准备和解析。双亲委派降低核心类被替换的风险，但应用服务器、插件和模块化系统可能使用不同的类加载层次。

## GC 诊断

GC 调优先定义目标：吞吐、P95/P99 延迟、堆占用和停顿预算。排障时结合 GC 日志、堆转储、对象分配速率、晋升失败和停顿阶段，不能看到 Full GC 就直接增大堆。

### 面试题：线上频繁 Full GC 如何排查？

参考答案要点：确认告警真实性与业务影响；分析 GC 日志和堆趋势；区分内存泄漏、突发分配、堆配置不当、元空间压力和显式 GC；用堆转储定位支配树和引用链；修复后用压测和长期指标回归。
