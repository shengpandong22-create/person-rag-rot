# Phase 12 验收报告：演示就绪度与项目自检

## 目标

Phase 12 是 V2 路线后的自然收口增强：在已有 RAG、面试、评分、画像、趋势和工作流轨迹之上，提供一个“面试演示就绪度”自检能力。

它解决的问题是：项目功能越来越多后，用户和面试官需要快速判断当前本地环境是否已经具备完整闭环演示条件。

本阶段不引入新基础设施，不修改数据库结构，只基于已有表进行只读统计。

## 实现内容

### 1. 演示就绪度服务

新增 `DemoReadinessService`，按以下维度检查本机默认用户的演示闭环：

- 是否已有知识库。
- 是否已有 READY 文档。
- 是否已有 workflow checkpoint。
- 是否完成过面试。
- 是否已有评分报告。
- 是否已有能力画像。

服务会输出：

- `score`：0～100 就绪分。
- `status`：`ready / partial / not_ready`。
- `checks`：逐项检查结果。
- `next_action`：下一步最应该做什么。

### 2. REST 自检接口

新增接口：

```text
GET /api/v1/demo/readiness
```

用于前端面板、演示前检查和面试官现场走读。

### 3. 前端运行态展示

`RuntimeInsights` 增加“演示就绪度”卡片，展示：

- 当前就绪百分比。
- 当前状态。
- 下一步建议。

这样页面顶部不仅能看 LLM、RAG、评分状态，还能看完整闭环是否已经准备好。
