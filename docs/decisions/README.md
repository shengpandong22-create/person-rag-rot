# 架构决策记录

本目录保存 Architecture Decision Record（ADR）。当一个技术选择影响多个模块、难以逆转或存在明显替代方案时，应新增 ADR。

命名格式：`ADR-NNN-简短名称.md`。

每份 ADR 至少包含：背景、决策、备选方案、选择理由、影响、风险和状态。ADR 一旦接受不删除；后续变化通过新的 ADR 替代。
