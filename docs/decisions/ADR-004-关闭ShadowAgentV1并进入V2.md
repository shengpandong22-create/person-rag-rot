# ADR-004：关闭 Shadow Agent V1 并进入 V2

- 状态：Accepted
- 日期：2026-10-05
- 结论：关闭 V1；V2 只优化已验证的路由与动作语义，不新增业务能力。

## V1 结论

真实模型 Development 中，V1 的工具选择准确率为86.11%、建议动作准确率为69.44%、稳定性为83.33%，低于预先提交门槛。安全指标均通过，但不具备演示或生产资格。

## V2 决策

1. `训练目标 → 首工具` 由确定性策略映射；
2. `训练目标/证据类型 → 最终业务动作` 由确定性策略映射；
3. LLM 仅能在首工具后选择最多一个不同的补充只读工具，或结束；
4. LLM 仅提供理由、受限 topic 与建议参数；未观察到的 topic 自动丢弃；
5. 继续保持三个只读工具、三步预算、人工确认、业务零写入、feature flag 默认关闭；
6. 使用全新 V2 Development；不重跑或调参 V1 数据。

## 为什么仍是 Agent Loop

首工具是业务策略边界，不是不确定性推理。模型仍要基于实际 observation 决定是否需要补充读取、选择哪个补充工具、何时结束，并生成受证据约束的说明和参数。该设计将不可出错的业务语义收回应用层，把不确定性保留在模型更适合处理的位置。
