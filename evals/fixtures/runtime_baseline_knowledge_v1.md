# AgentMentor runtime baseline fixture

## RAG 回答证据不足

AgentMentor 的 RAG 回答需要显式处理证据不足。当检索 chunk 无法充分支持用户问题时，
系统返回证据不足，而不是把模型常识伪装成知识库结论。引用只允许来自当前请求检索出的 chunk。

## RRF 混合检索

RRF 在混合检索中融合向量检索与全文检索的候选排名。它降低系统对单纯语义相似度或
单纯字面关键词匹配的依赖。

## 面试工作流 checkpoint

面试工作流需要 checkpoint，因为它不是一次 HTTP 请求。checkpoint 记录标识符、当前节点、
题目序号和是否等待回答，支持刷新后的安全恢复与幂等答案提交。

## 最终总分应用层计算

最终总分由应用层而不是 LLM 直接计算。评分模型只提供四个维度和诊断信息，应用层按 rubric
计算总分；低置信或争议结果进入复核，避免污染能力画像。

## 能力画像知识库绑定

能力画像需要与知识库绑定。一个用户在 Java 知识库和 Agent 知识库中的能力证据不同，
混用画像会让后续训练推荐失真。
