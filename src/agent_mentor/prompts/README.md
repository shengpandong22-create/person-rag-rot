# Prompt versions

Prompt templates are added with the feature that consumes them.

- `answer_generation_v1.md`: Phase 2 grounded answer contract and citation rules.
- `interview_question_v1.md`: Phase 3 interview question contract.
- `evaluation_v1.md`: Phase 4 scoring contract, citation rules, and review reasons.
- `review_v1.md`: Phase 4 independent review contract for low-confidence or disputed results.
